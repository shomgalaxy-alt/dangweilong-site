# 网站部署方式对比与配置

> 两种部署方式，任选其一。系统（publisher_agent）会自动把文章生成到 www/ 目录，
> 部署层负责把 www/ 变成可访问的网站。
> 更新日期：2025-08-22

---

## 方式 A：服务器 Nginx 直出（推荐，全自动闭环）

**适用**：已买服务器，域名解析到服务器 IP（国内需备案）。

```bash
# 服务器上执行
apt-get install -y nginx
mkdir -p /var/www/dwl
cp -R /root/dwl/www/* /var/www/dwl/
cp /root/dwl/deploy/nginx-dangweilong.conf /etc/nginx/sites-available/dangweilong.com
ln -s /etc/nginx/sites-available/dangweilong.com /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

# HTTPS（免费证书）
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d dangweilong.com
```

**全自动发布**：把 `/root/dwl/www` 软链到 `/var/www/dwl`，每日 cron 生成新文章后自动可见：
```bash
ln -s /root/dwl/www /var/www/dwl   # 之后 www 更新即网站更新
```

## 方式 B：GitHub Pages（免费、免备案、全球 CDN）

**适用**：不想备案，或还没买服务器。

### 步骤
1. GitHub 建一个仓库，比如 `dangweilong/dangweilong.github.io`（必须是这个命名规则）
2. 服务器上把 www/ 作为该仓库的 working copy：
```bash
cd /root/dwl/www
git init
git remote add origin git@github.com:dangweilong/dangweilong.github.io.git
git checkout -b main
git add -A && git commit -m "init"
git push -u origin main
```
3. GitHub 设置里开启 Pages（Source: main branch, root）

**全自动发布**：publisher_agent 每次生成文章后自动执行 `git add/commit/push`，GitHub Pages 自动更新（1-2 分钟生效）。

**自定义域名**（可选）：仓库设置 Pages → Custom domain 填 dangweilong.com，并把 DNS CNAME 指向 dangweilong.github.io。

## 对比

| 维度 | Nginx 直出 | GitHub Pages |
|------|-----------|--------------|
| 费用 | 服务器费（已有） | 免费 |
| 备案 | 国内需备案 | 免备案 |
| 发布速度 | 即时 | 1-2 分钟 |
| 全自动 | ✅ 软链即更新 | ✅ publisher 自动 push |
| HTTPS | certbot 免费证书 | 自带 |
| 适合 | 已有服务器 | 未买服务器/免备案 |

---

## publisher_agent 与部署的衔接

publisher_agent 已经内置 `git_commit_and_push()`：
- 若 `www/` 是 git 仓库（GitHub Pages 方式），自动 push
- 若 `www/` 是普通目录（Nginx 软链方式），跳过 git，直接写文件

两种方式都不需要改代码，配置好环境即可。
