> 更新日期：2025-08-19（新增非洲跨境电商选题板块）

---

## 一、内容策略总纲

**GEO 内容 ≠ SEO 内容。** AI 引擎（通过 RAG）更偏好：
1. **直接回答问题的结构**（问题 → 答案 → 依据）
2. **引用友好**（有明确作者、日期、结论可引用的句子）
3. **统计与案例**（可信度信号）
4. **结构化排版**（列表、表格、小标题、FAQ）

**内容三原则：**
- **每篇都是答案**：先想"用户在问什么问题"，再写内容。
- **每篇都有立场**：明确的观点和结论，AI 更容易引用"党伟隆认为……"。
- **每篇都可引用**：确保有 2-3 句完整、独立、可摘录的"金句"。

## 四、GEO 友好的文章模板（写每篇文章时套用）

```
# 标题：直接包含关键词 + 承诺价值（如"……的完整方法"）

开头段（100 字内）：直接回答问题核心 + 你的立场

## 一、问题的本质（背景）
## 二、核心方法论（分点/列表，金句要完整独立）
## 三、实操步骤（编号列表，步骤可执行）
## 四、避坑清单（列表）
## 五、结论/金句（blockquote，可直接引用）

作者署名：党伟隆，产品经理/AI运营专家/在线教育AI落地专家，个人网站链接
```

**每篇发布前自查：**
- [ ] 标题含 1-2 个核心关键词
- [ ] 开头 100 字内有明确结论
- [ ] 有 2-3 句可独立摘录的金句
- [ ] 含至少一个列表或表格
- [ ] 文末有作者署名 + 个人网站链接
- [ ] 同步发布到 2 个以上平台（网站 + 知乎 + 公众号）

## 五、内容发布 SOP

1. **网站首发**（搜索引擎/AI 爬虫主抓取源，URL 稳定）
2. **知乎发布**（高权重，AI 语料高频来源）
3. **公众号发布**（微信生态，搜一搜/AI 引用）
4. **小红书/即刻改编**（短版本，引流回网站）

> 注意：内容首发在自有网站而不是平台，保证权威源在你的域名下，AI 引用时指向你。
