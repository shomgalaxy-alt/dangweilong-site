## 二、推送到远程仓库（3 种方式选一）

### 方式 A：GitHub（推荐，免费）
```bash
# 1. 在 github.com 新建一个私有仓库（如 dangweilong/dwl）
# 2. 本机执行：
git remote add origin git@github.com:dangweilong/dwl.git
git push -u origin main
```

### 方式 B：Gitee（国内访问快）
```bash
git remote add origin git@gitee.com:dangweilong/dwl.git
git push -u origin main
```

### 方式 C：服务器直传（不经过第三方仓库）
```bash
# 在服务器上：scp -r /root/dwl 已由 setup_server.sh 处理
# 或本机执行：
scp -r /Users/xsn/Documents/新十年/dwl root@服务器IP:/root/dwl
```

## 三、安全说明（重要）

- `.gitignore` 已排除：`.env`、`data/`（运行时数据）、`logs/`、`backups/`
- **API Key 永远不会进入 git 历史**——只在服务器上配置 `agents/.env`
- 推送到 GitHub 建议用**私有仓库**，避免策略文档公开

## 四、服务器部署三步

```bash
# 1. clone（或 scp）
git clone <你的仓库地址> /root/dwl && cd /root/dwl

# 2. 一键初始化（装依赖、建目录、写 cron）
bash scripts/setup_server.sh

# 3. 配置 API Key
cp agents/.env.example agents/.env
# 编辑 agents/.env 填入 DeepSeek/豆包/千问/元宝 的 Key

# 4. 测试运行
python3 agents/orchestrator.py
```

## 五、部署后网站更新流

```
服务器 cron 每日 08:00
  └── orchestrator → 指挥官 → content_agent 生成
                                  └── publisher_agent 写入 www/ + git push
                                        └── GitHub Pages / Nginx 自动发布
```

- 若用 GitHub Pages：把 `www/` 设为独立仓库，publisher 自动 push 即可上线
- 若用服务器 Nginx：`ln -s /root/dwl/www /var/www/dwl` 即可
