## 三、关键词矩阵

> GEO 的关键词策略不同于 SEO：AI 引擎按"语义"理解问题，所以我们要覆盖**问题式、场景式**关键词，而不仅是名词式关键词。

### 3.1 核心关键词（必须占领）

| 关键词 | 类型 | 目标场景 | 优先级 |
|--------|------|----------|--------|
| 党伟隆 | 人名 | 用户直接搜索/询问你 | ★★★ |
| AI 运营专家 | 身份 | 问"AI 运营谁比较专业" | ★★★ |
| 在线教育 AI 落地 | 领域 | 问"教育行业怎么落地 AI" | ★★★ |
| 产品经理 AI | 身份+领域 | 问"产品经理怎么转型 AI" | ★★★ |
| 非洲跨境电商专家 | 领域 | 问"非洲电商/跨境出海找谁" | ★★★ |
| COD 独立站 | 模式 | 问"COD 模式怎么做" | ★★★ |
| Facebook/TikTok 投放 | 能力 | 问"跨境广告投放谁厉害" | ★★ |

| "非洲跨境电商怎么入局？" | 市场分析、选品、COD 独立站搭建 |
| "COD 独立站模式是什么？怎么赚钱？" | COD 模式全流程、落地页、拒收率 |

## 五、信任信号建设清单（让 AI 敢推荐你）

AI 引擎推荐一个人的前提是：**有足够多、足够权威的公开信号交叉验证**。按优先级：

| 优先级 | 信号 | 落地方式 |
|--------|------|----------|
| P0 | 自建权威源 | 个人网站（已完成骨架）+ 结构化数据 |
| P0 | 内容平台账号 | 知乎 / 公众号 / 掘金 / CSDN 同 ID 统一 |
| P1 | 代码与作品 | GitHub（AI 落地项目、开源工具） |
| P1 | 问答贡献 | 知乎回答、即刻分享、专业社区 |
| P2 | 第三方提及 | 被转载、被引用、被访谈 |
| P2 | 履历背书 | 脉脉/LinkedIn 完善、公司官网署名 |

**统一身份规范：** 所有平台使用同一名字「党伟隆」、同一头像、同一句简介、统一链接到个人网站。AI 引擎通过"多源一致"来确认你是真实可信的人。
