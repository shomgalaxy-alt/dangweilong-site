# 党伟隆 GEO 多智能体自动化运营系统架构

> 运行环境：个人 Linux 服务器（用户自购）
> 调度方式：cron 定时任务 + 主控编排器
> 更新日期：2025-08-19 · 版本 v1.0

---

## 二、智能体角色分工

| # | 智能体 | 职责 | 产出 | 触发 |
|---|--------|------|------|------|
| 🤖 | `commander_agent` 指挥官 | 每日读取运营状态（AI 可见度趋势/内容库存/选题使用/草稿积压），调用 LLM **制定当日任务计划**，再分派给执行智能体；LLM 决策失败自动降级为默认计划 | `data/plans/日期.json` 决策存档 | 每日（由 orchestrator 启动） |
| ① | `content_agent` 内容生成 | 按指挥官计划（或默认策略）调用 LLM 生成：深度文、短评、问答 | `data/content/日期/*.md` | 指挥官分派 |
| ② | `publisher_agent` 发布 | 网站发布（HTML+sitemap+git 部署）、平台草稿 | `www/` + `data/drafts/` | 指挥官分派 |
| ③ | `monitor_agent` 监控 | **四引擎**（DeepSeek/豆包/通义千问/腾讯元宝）分别提问检测"党伟隆"提及率，逐引擎存档趋势 | `data/monitor/*.json` | 指挥官分派 |
| ④ | `report_agent` 周报 | 汇总本周数据生成网页周报 | `data/reports/周报.html` | 每周日 cron |

## 四·五、指挥官决策机制（关键设计）

**指挥官每天做什么：**
1. **收集情报**：读取监控趋势（最近 7 次 AI 可见度）、累计产量、已用选题、草稿积压、星期几
2. **LLM 决策**：把情报喂给 LLM，让它输出结构化任务计划（JSON）：是否生成深度文、选什么主题、短评/问答数量、重点关键词、决策理由
3. **存档**：`data/plans/日期.json` 记录每日决策（可追溯、可复盘）
4. **分派**：按计划带参数调用 内容生成 → 发布 → 监控

**智能决策示例：**
- 命中率连续为 0 → 指挥官会加大深度文产出、聚焦高价值选题
- 草稿积压 ≥6 份 → 指挥官会减少当天生成量，优先消化存量
- 已用选题重复 → 指挥官从选题池选新主题

**容错设计：** LLM 决策失败时自动降级为默认计划（等同旧版固定节奏），保证系统不中断。

## 五、调度（cron 配置）

```cron
# 每日 08:00 全链路：生成→发布→监控
0 8 * * * cd /root/dwl && python3 agents/orchestrator.py >> logs/cron.log 2>&1

# 每周日 20:00 生成周报
0 20 * * 0 cd /root/dwl && python3 agents/report_agent.py >> logs/report.log 2>&1

# 每周一 03:00 备份
0 3 * * 1 cd /root/dwl && tar czf backups/$(date +\%Y\%m\%d).tar.gz data/ www/ site/ agents/
```

## 六、自动化程度与人工触点

| 环节 | 自动化 | 人工触点 |
|------|--------|----------|
| 内容生成 | ✅ 全自动 | 偶尔抽查质量 |
| 网站发布 | ✅ 全自动（git 自动部署） | 无 |
| 知乎发布 | 🟢 草稿生成自动；发布需手动（官方 API 可选配置） | 看周报后一键发 |
| 公众号 | 🟡 草稿自动 | 手动粘贴发布 |
| 小红书 | 🟡 草稿自动 | 手动粘贴发布 |
| 监控 | ✅ 全自动 | 无 |
| 周报 | ✅ 全自动 | 打开网页看 |

> 设计原则：**"自动生成 + 人工发布"是安全底线**（避免封号），网站与监控做到真正全自动。随着知乎官方 API 成熟，可逐步接入真自动发布。
