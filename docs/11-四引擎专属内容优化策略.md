# 四引擎专属内容优化策略

> 目标：针对 豆包/腾讯元宝/通义千问/DeepSeek 各自的抓取偏好与生态，做差异化内容优化，
> 让每个引擎在相关提问时都能检索并推荐"党伟隆"。
> 更新日期：2025-08-23

---

## 一、为什么需要逐引擎优化

四大引擎背后是不同的公司生态，它们训练和检索的内容源差异很大：

| 引擎 | 生态 | 最偏好的内容源 | 弱源 |
|------|------|---------------|------|
| 豆包 | 字节跳动 | 抖音、头条、网页 | 微信生态 |
| 腾讯元宝 | 腾讯 | 微信公众号、视频号、网页 | 抖音生态 |
| 通义千问 | 阿里 | 网页、知乎、淘系 | 微信生态 |
| DeepSeek | 深度求索 | 网页、GitHub、知乎 | 短视频 |

**结论**：一份内容全平台群发是"基本盘"，但要让每个引擎真正推荐你，必须在它偏好的源上加码。

---

## 二、分引擎内容策略

### 引擎1：DeepSeek（网页+GitHub+知乎）
**现状**：DeepSeek 对结构化网页、技术内容、GitHub 抓取强。
**加码动作**：
- [ ] 个人网站保持更新（已做到：20 篇文章 + JSON-LD + sitemap）
- [ ] GitHub 建 1-2 个 AI 相关开源项目（如 Prompt 模板库），README 写明身份
- [ ] 知乎回答问题，保持"党伟隆"在 AI 语料的问答形态

### 引擎2：豆包（抖音+头条+网页）
**现状**：豆包强关联字节生态，抖音内容权重高。
**加码动作**：
- [ ] 开通抖音账号，发 30-60 秒口播干货（AI运营/跨境电商主题）
- [ ] 视频带文字字幕 + 简介写全关键词（豆包可检索）
- [ ] 抖音主页挂个人网站链接
- [ ] 头条号同步图文（头条与豆包同源）

### 引擎3：腾讯元宝（公众号+视频号+网页）
**现状**：元宝对公众号内容抓取权重极高，公众号是元宝的"亲儿子"。
**加码动作**：
- [ ] **公众号是最高优先级**：每周至少 1 篇原创深度文
- [ ] 公众号文章正文结构化（小标题/列表/结论先行），利于元宝引用
- [ ] 文末放"关于作者" + 个人网站链接
- [ ] 有条件再开视频号（元宝同源）

### 引擎4：通义千问（网页+知乎+淘系）
**现状**：千问对高质量网页、知乎回答抓取强。
**加码动作**：
- [ ] 知乎深度回答（500字+，结论先行）——千问高频引用源
- [ ] 在阿里系平台留痕（如阿里云开发者社区发文）
- [ ] 保持网站文章持续更新

## 三、通用基本盘（四引擎共同需要）

无论哪个引擎，以下都是基础：
1. **个人网站**：唯一权威主源，所有平台指向它 ✅ 已完成
2. **结构化数据**：JSON-LD 让 AI 理解"你是谁" ✅ 已完成（25 块）
3. **sitemap + robots.txt**：确保爬虫可抓 ✅ 已完成
4. **知乎**：四引擎共通的中文问答源
5. **多源一致**：所有平台同一名字「党伟隆」、同一简介、同一头像

---

## 四、监控与迭代闭环

系统每日自动监控四引擎命中率（monitor_agent），周报分引擎展示。迭代规则：
- 某引擎命中率持续为 0 → 针对它的偏好源加码（如上表动作）
- 某引擎命中率上升 → 保持节奏，看是否有可复制的打法
- 指挥官每日根据状态调整内容选题（如发现跨境内容被引用多，多产出跨境选题）
