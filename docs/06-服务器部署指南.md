# 多智能体自动化系统 · 服务器部署指南

> 目标：把 GEO 自动化系统部署到你的个人服务器，实现全自动运营。
> 部署时间：约 30 分钟（不含买服务器）

---

## 一、买服务器（5 分钟）

| 项 | 建议 |
|----|------|
| 云厂商 | 阿里云 / 腾讯云 / 华为云（国内访问快） |
| 配置 | 2C4G 起（本系统负载极低，1C2G 也够用） |
| 系统 | **Ubuntu 22.04 LTS** |
| 计费 | 按量付费或包年（新人约几十元/年优惠） |
| 安全组 | 放行 22（SSH）、80/443（如需挂网站） |

买好后你会得到一个公网 IP，例如 `123.45.67.89`。

---

## 二、上传项目到服务器（10 分钟）

### 方式 A：git（推荐，后续更新方便）
在服务器上：
```bash
apt-get update && apt-get install -y git
git clone <你的仓库地址> /root/dwl
```
（需要先把本目录推送到 GitHub/Gitee 私有仓库）

### 方式 B：scp 直接传
```bash
# 在你本地电脑执行（替换 IP 和路径）
scp -r /Users/xsn/Documents/新十年/dwl root@123.45.67.89:/root/dwl
```

---

## 三、一键初始化（5 分钟）

```bash
cd /root/dwl
bash scripts/setup_server.sh
```

脚本会自动：
1. 安装 Python3 / git / cron
2. 创建数据目录
3. 配置 cron 定时任务（每日 08:00 全链路 + 每周日 20:00 周报 + 每周一备份）
4. 提示配置 API Key

---

## 四、配置 API Key（2 分钟）

编辑 `agents/config.py`（或 `agents/.env`），填入：

```python
LLM_API_KEY = "sk-你的DeepSeek密钥"   # 从 https://platform.deepseek.com 获取
```

DeepSeek API 价格极低（监控和生成内容每日消耗通常不到 0.1 元）。

---

## 五、测试运行（2 分钟）

```bash
cd /root/dwl

# 1. 手动跑一次完整链路（观察输出是否正常）
LLM_MOCK=1 python3 agents/orchestrator.py   # 先测 mock（不花钱）
python3 agents/orchestrator.py              # 真实运行

# 2. 生成周报测试
python3 agents/report_agent.py

# 3. 查看日志
tail -f logs/cron.log
```

---

## 六、验证 cron 已生效

```bash
crontab -l
# 应看到：
# 0 8 * * * cd /root/dwl && python3 agents/orchestrator.py >> logs/cron.log 2>&1
# 0 20 * * 0 cd /root/dwl && python3 agents/report_agent.py >> logs/report.log 2>&1
```

---

## 七、网站部署（可选）

系统把文章生成到 `www/` 目录。两种部署方式：

### 方式 A：www 目录挂到 Nginx（服务器直出网站）
```bash
apt-get install -y nginx
ln -s /root/dwl/www /var/www/dwl
# 配置 nginx 站点指向 /var/www/dwl
```
优点：全自动闭环（生成→发布→网站更新）
前提：域名解析 A 记录指向服务器 IP，需备案（国内）

### 方式 B：继续用 GitHub Pages
把 `www/` 目录做成 git 仓库，自动 push：
```bash
cd /root/dwl/www
git init && git remote add origin <你的pages仓库>
# publisher_agent 已内置 git add/commit/push 逻辑
```
优点：免备案、免费、全球 CDN

## 八、日常运维

| 操作 | 命令 |
|------|------|
| 看每日运行日志 | `tail -20 /root/dwl/logs/cron.log` |
| 看周报 | 打开 `/root/dwl/data/reports/` 下最新的 HTML |
| 手动触发一轮 | `cd /root/dwl && python3 agents/orchestrator.py` |
| 手动发布草稿 | 查看 `/root/dwl/data/drafts/今天/` 的草稿，复制到知乎/公众号/小红书 |
| 备份 | 每周一自动备份到 `backups/`，或手动 `tar czf backups/手动.tar.gz data/` |

---

## 九、安全建议

- SSH 改密钥登录，禁用密码登录
- 防火墙只开 22 / 80 / 443
- API Key 只存在服务器上，别提交到公开仓库
- 每周看一次周报即可，平时无需人工干预

---

## 十、故障排查

| 症状 | 排查 |
|------|------|
| 每日没跑 | `crontab -l` 看任务在不在；`cat /root/dwl/logs/cron.log` 看报错 |
| LLM 调用失败 | 检查 API Key 是否有效、余额是否充足 |
| 网站没更新 | 看 publisher 日志；确认 www 是 git 仓库且有远程 |
| 周报数据为空 | 确认 monitor 跑过（data/monitor/ 下有记录） |
