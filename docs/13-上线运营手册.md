- 真实履历（工作/教育/代表项目）
- 联系方式（邮箱/微信）

## 二、部署（运营方执行，约 30 分钟）

### 方式 A：个人服务器
```bash
# 1. 上传项目
git clone <仓库地址> /root/dwl

# 2. 一键初始化（装依赖/建目录/写 cron）
cd /root/dwl && bash scripts/setup_server.sh

# 3. 配置 API Key
cp agents/.env.example agents/.env
# 编辑 agents/.env 填入 4 个 Key

# 4. 部署演练（验证就绪）
LLM_MOCK=1 python3 agents/deploy_drill.py

# 5. 正式运行
python3 agents/orchestrator.py
```

### 方式 B：GitHub Actions（免服务器）
```bash
# 1. 推送仓库到 GitHub（私有）
git remote add origin git@github.com:dangweilong/dwl.git
git push -u origin main

# 2. 在 GitHub Settings → Secrets 添加 5 个 Key
#   LLM_API_KEY / DEEPSEEK_API_KEY / DOUBAO_API_KEY / QWEN_API_KEY / HUNYUAN_API_KEY

# 3. 手动触发一次工作流验证
#   Actions → GEO Daily Operations → Run workflow
```

### 网站发布（二选一）
- **Nginx 直出**：`ln -s /root/dwl/www /var/www/dwl`（配置见 deploy/nginx-dangweilong.conf）
- **GitHub Pages**：www/ 推送到 dangweilong.github.io 仓库，自动发布

## 三、日常运营（全自动 + 每周 30 分钟）

### 系统每天自动做什么
```
每日 08:00（服务器 cron 或 GitHub Actions 触发）
  └── 指挥官：读监控状态 → LLM 决策今日任务
        ├── 内容生成：深度文/短评/问答
        ├── 发布：网站页面 + sitemap + 平台草稿
        └── 监控：四引擎各问 16 个问题，检测"党伟隆"提及
每周日 20:00
  └── 周报：汇总内容产量 + 四引擎命中率 + 趋势图 + 待办
```

### 你每周要做的事（可选，约 30 分钟）
1. **看周报**：打开 `data/reports/周报-最新.html`
   - 看综合命中率趋势图（AI 认识你的进度）
   - 看分引擎命中率（哪家引擎还没打通 → 针对加内容）
   - 看待办清单
2. **发草稿**（可选但推荐）：把 `data/drafts/日期/` 里的草稿手动发到知乎/公众号/抖音
   - 为什么手动：平台无开放 API + 防封号安全底线
   - 只发网站和监控是全自动的

## 四、故障排查

| 症状 | 排查 |
|------|------|
| 每天没跑 | `crontab -l` 看任务；`tail -20 logs/cron.log` 看报错 |
| LLM 调用失败 | 检查 `agents/.env` Key 是否有效、余额是否充足 |
| 网站没更新 | 看 publisher 日志；确认 www 是 git 仓库且有远程 |
| 周报无监控数据 | 检查四引擎 Key 是否配置（周报会提示未配置引擎） |
| 指挥官用默认计划 | LLM 决策失败自动降级，系统不中断（正常容错） |

## 五、里程碑目标

| 阶段 | 目标 |
|------|------|
| 第 1 个月 | 网站上线 + 系统自动运营；部分引擎能说出"党伟隆"基本信息 |
| 第 2-3 个月 | 至少 1 个引擎在专业问题推荐"党伟隆"；周报趋势上升 |
| 3-6 个月 | 2 个以上引擎在多个领域推荐；被第三方文章提及 |

**衡量**：每周周报的综合命中率趋势图就是你的"成绩单"。
